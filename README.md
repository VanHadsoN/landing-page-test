# Тестовый лендинг

Статическая лендинг‑страница (HTML/CSS/JS) с адаптивной версткой, якорной навигацией, бегущей строкой и каруселями.

## Стек

- **HTML**: `index.html`
- **CSS**: `styles.css`
- **JavaScript**: `main.js`

## Возможности

- **Якорная навигация с плавным скроллом** по ссылкам вида `#...`.
- **Skip link**: ссылка «Перейти к содержимому» для клавиатурной навигации.
- **Бегущая строка (ticker/marquee)**:
  - автоматически дублирует элементы, чтобы «лента» гарантированно перекрывала ширину экрана,
  - скорость привязана к ширине контента,
  - пересчет при `resize` с debounce.
- **Анимации появления по скроллу** через `IntersectionObserver`.
- **Слайдер “Этапы”**:
  - на десктопе — сетка,
  - на мобильных (≤ 900px) — карточный слайдер с точками и кнопками, без зацикливания.
- **Карусель “Участники”**:
  - зацикливание через клоны элементов (clones),
  - автопрокрутка,
  - пауза при hover/focus,
  - адаптивное количество карточек на экран: 1 / 2 / 3.

## Структура проекта

```text
.
├─ index.html   # разметка страницы
├─ styles.css   # стили и адаптив
├─ main.js      # интерактив (якоря/тикер/слайдеры/анимации)
└─ README.md
```

## Запуск локально

Проект не требует сборки.

### Вариант 1: открыть файл напрямую

Откройте `index.html` в браузере (подойдет для быстрой проверки верстки).

### Вариант 2: запустить статический сервер (рекомендуется)

Любым удобным способом из папки проекта, например:

- **Node.js (npx)**:

```bash
npx serve .
```

После запуска откройте адрес, который покажет сервер.
